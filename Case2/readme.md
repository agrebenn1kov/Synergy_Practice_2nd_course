# Задача

Написать тестовую программу, которая демонстрирует работу методов базового и производного классов.

## Решение

### В качестве ЯП был выбран Python3
### В качестве примера используется иерархия классов животных:
#### Базовый класс Animal — содержит общие свойства (name, age) и методы (speak(), move(), info()).   
#### 2. Производные классы Dog и Cat — наследуют Animal и: переопределяют метод speak(), расширяют метод info() через super(), добавляют собственные методы (fetch(), climb()).   
#### 3. Тестовая функция test_classes() — последовательно демонстрирует все аспекты ООП.
