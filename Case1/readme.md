# Задача

Дан одномерный массив A размерности N. Необходимо найти сумму отрицательных элементов, расположенных между максимальным и минимальным элементами массива.

## Решение

### В качестве ЯП был выбран Python3
### Алгоритм решения состоит из следующих шагов:
#### 1. Ввод данных — пользователь вводит размерность N и N целых чисел через пробел.   
#### 2. Поиск границ — находим индексы максимального (idx_max) и минимального (idx_min) элементов с помощью max(), min() и index().   
#### 3. Определение интервала — вычисляем левую и правую границы: left = min(idx_max, idx_min), right = max(idx_max, idx_min).
#### 4. Суммирование — проходим по элементам с индексами от left+1 до right-1, отбираем отрицательные и складываем их.
#### 5. Вывод результата — выводим исходный массив, границы,промежуточные элементы и итоговую сумму.
